# Архив форума пользователей Visio (visio.getbb.ru)

**https://visio-getbb-ru.github.io/**

Копия только для чтения форума «Форум пользователей Visio» — форума по вопросам применения
и программирования в Microsoft Visio, работавшего на visio.getbb.ru с 2009 года.
Сохранена в ноябре 2026 года, когда сервис getBB перестал обслуживать форумы на своих доменах.

Что в архиве:

- 1575 тем, около 18 000 сообщений, 37 разделов — в оформлении оригинального форума;
- вложения (1525 файлов), картинки из сообщений, галерея форума;
- поиск по сообщениям (по словам, автору, разделам), работающий прямо в браузере.

Профили пользователей, личные сообщения, вход и ответы в архив не входят.

## Как устроен этот репозиторий

Здесь только инструкция сборки: [`.github/workflows/build.yml`](.github/workflows/build.yml).
GitHub Actions берёт исходные данные (сохранённые страницы форума, вложения, картинки, скрипты),
собирает статический сайт и поисковый индекс [Pagefind](https://pagefind.app) и публикует его в GitHub Pages.
Пересобрать сайт: вкладка **Actions** → **Build and publish the archive** → **Run workflow**.
